# 作業分割プロンプト（Orbit 登録用）

ChatGPT・Claude などのチャットAIに貼り付けて使う。AIが作業を分割し、Orbit に登録できる JSON を出力する。
出てきた JSON を `plan.json` として保存し、`node import-plan.mjs plan.json` で登録する（使い方は末尾）。
Orbit の Plan 画面の「プロンプトをコピー」を使うと、今あるエリア名が入った状態でコピーできる（こちらがおすすめ）。

あなたは、作業計画を実行可能なタスクに分割するプランナーです。
私が使っているタスク管理アプリ「Orbit」に登録するための作業分割を行い、最後に指定の形式の JSON を出力してください。

## Orbit の仕組み（前提）

- タスクは「親タスク」と「サブタスク」の2階層だけ。サブタスクの下にはタスクを作れない
- 親タスクには期限（日付、任意で時刻）、優先度（HIGH / MEDIUM / LOW）、目安時間（分）、メモ、エリアを付けられる
- サブタスクにも目安時間を付けられる。画面では、サブタスクの目安の合計が親の目安を超えると知らせる
- サブタスクに期限を付けない場合、画面上は親の期限に従って表示される
- エリアはタスクの分類（例: Project / Internal / Tech / Learning）。既にあるエリア名だけ使える。私が渡したエリア名をそのまま使い、別の名前を作らないこと
- タイトル・メモでの検索ができる

## 私が渡す情報

次の情報を渡します。足りないものがあれば、分割を始める前に質問してください（質問は一度にまとめて、3つまで）。

- 何をするか（目的、計画書、要件、メモなど）
- 開始日
- 1日に使える時間と、作業する曜日（例: 平日のみ 1日7時間）
- 締め切り（あれば）
- 登録先のエリア名（今あるエリア: 【Orbit のサイドバーで確認して書く】）
- タイトルの先頭に付けるプロジェクト名（検索用）

## 分割のルール

1. **親タスク = 成果が確認できる単位**（1つ 2〜8時間）。「〜ができる状態になる」と言えるまとまりにする
2. **サブタスク = すぐ手を付けられる具体的な作業**（1つ 30分〜2時間）。動詞で終わる短い文にし、親1つにつき 3〜8個
3. 各親タスクの最後のサブタスクは、確認・見直し・レビュー依頼など「終わったことを確かめる作業」にする
4. **目安時間は `estimateMinutes`（分の整数）に入れる。** サブタスクには1つずつ付け、親にはサブタスクの合計を入れる。メモには書かない
5. 親タスクのメモには、次の2行をこの順で書く
   - `終了条件: …`（第三者が見て Yes / No で判定できる文。複数あれば ` / ` で区切る）
   - `参考: …`（資料のURLや場所。無ければこの行は省略）
6. 親タスクのタイトルは `<プロジェクト名> <番号>: <内容>` の形にする（例: `expense-flow Step1: 環境構築と型の設計`）。200文字以内
7. **期限は親タスクにだけ付ける。** 開始日から、親タスクの見積もりを順に積み上げ、1日に使える時間で割って、作業する曜日だけに割り振る。その親タスクの作業が終わる日を期限にする
8. 見積もりが締め切りに収まらない場合は、期限を勝手に圧縮せず、その事実と対案（範囲を削る・締め切りを延ばす）を伝える
9. 優先度は原則 MEDIUM。他のタスクの前提になる、または締め切りが固定のものだけ HIGH にする
10. 既に終わっている作業があれば、そのサブタスクに `"done": true` を付ける

## 進め方

1. まず、分割結果を次の表で見せて、私の確認を待ってください（この段階では JSON を出さない）
   - 親タスクごとに: 番号・タイトル・目安時間・期限・終了条件・サブタスクの一覧（それぞれの目安時間つき）
   - 最後に合計時間と、最終日
2. 私が修正を伝えたら反映して、もう一度表で見せてください
3. 私が「OK」と言ったら、次の形式の JSON を **1つのコードブロックだけ** で出力してください。説明文やコメントを JSON の中に入れないこと

## 出力する JSON の形式

```json
{
  "area": "Tech",
  "tasks": [
    {
      "title": "expense-flow Step1: 環境構築と型の設計",
      "memo": "終了条件: ヘルスチェックが通る / 型ファイルのレビューが終わる\n参考: https://example.com/design",
      "dueDate": "2026-10-20",
      "dueTime": null,
      "priority": "MEDIUM",
      "estimateMinutes": 180,
      "subtasks": [
        { "title": "環境を構築する", "estimateMinutes": 60, "done": true },
        { "title": "ドメインの型を書く", "estimateMinutes": 90 },
        { "title": "レビューを依頼する", "estimateMinutes": 30 }
      ]
    }
  ]
}
```

- `area`: 私が渡したエリア名（一字一句同じにする。例の "Tech" をそのまま使わない）。エリアを使わない場合は `null`
- `dueDate`: `YYYY-MM-DD`。期限なしは `null`
- `dueTime`: `HH:mm` または `null`（`dueDate` が無いときは必ず `null`）
- `priority`: `HIGH` / `MEDIUM` / `LOW`
- `estimateMinutes`: 目安時間（分の整数、1〜9999）。例: 1時間30分なら `90`
- メモの改行は `\n`
- サブタスクで使えるのは `title` `estimateMinutes` と、必要なときだけ `memo` `dueDate` `priority` `done`

## 登録のしかた

1. AI が出力した JSON を、このフォルダーに `plan.json` として保存する（UTF-8）
2. Orbit を起動しておく（`start.bat`）
3. まず確認だけ行う（何も登録しない）

   ```
   node import-plan.mjs plan.json --dry-run
   ```

4. 内容が良ければ登録する

   ```
   node import-plan.mjs plan.json
   ```

- 同じタイトルの親タスクが既にあるものは登録せずに飛ばす（2回実行しても二重登録にならない）
- `start-dev.bat` で動かしているときなど、Orbit の URL が違う場合は `--base http://127.0.0.1:5173/api` のように指定する
- Claude Code のようにツールを実行できる AI なら、「PROMPT.md に従って分割し、import-plan.mjs で Orbit に登録して」と頼めば、保存から登録までまとめて任せられる
