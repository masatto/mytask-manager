# Orbit

自分専用のタスク管理アプリ。PC のブラウザで使い、データは自分の PC の中だけに保存する。

> **名前の由来**：自分の「今日」を中心に、すべてのタスクがその周りを回っている――というイメージ。ロゴの惑星が今日、軌道を回る衛星がこれからのタスク。
>
> リポジトリ名・データフォルダー（`.mytask-manager`）・バックアップ形式の識別子（`mytask-manager-backup`）は、既存のデータや過去のバックアップを読めるよう旧名のまま。

- **今日やること**が一目でわかる：Today（今日）／Upcoming（これから）／Someday（いつか）／Done（完了）の4つのビュー。期限切れは赤で強調
- **期限と優先度で並ぶ**：期限は「日付のみ」「日付＋時刻」の両方に対応
- **サブタスク**（1階層）：進捗表示、未完了が残る親の一括完了
- **繰り返しタスク**：毎日／毎週（曜日指定）／毎月（日付・末日）。日付が来たら自動で生成
- **バックアップ**：JSON でエクスポート／インポート。毎日1回の自動バックアップ（直近14日分）
- **検索**：タイトル・メモで全タスクを検索
- **自然な書き方で追加**：`明日 15:00 歯医者 !高` と入れるだけで、期限・時刻・優先度まで入る（日付は `今日` `明日` `金曜` `来週月曜` `10/20` `3日後` など、時刻は `15:00` `9時半` など）
- **延期**：期限切れや今日のタスクを、行から「明日へ」でワンクリック延期。期限切れは「すべて今日へ」でまとめて移せる（どちらも元に戻せる）
- **今日の進み具合**：Today の見出しに「2/5 完了」とバーで表示
- **複製・リンク**：タスクをサブタスクごと複製できる。メモに書いた URL はクリックで開ける
- **キーボード操作**：`N` 追加、`/` 検索、`Esc` パネルを閉じる

## 必要なもの

| もの | 備考 |
|---|---|
| Windows 10/11 | `start.bat` / `stop.bat` は Windows 用 |
| JDK 21 | [Eclipse Temurin 21](https://adoptium.net/) を推奨（`winget install EclipseAdoptium.Temurin.21.JDK`）。`JAVA_HOME` がなくても `C:\Program Files\Eclipse Adoptium\jdk-21*` を自動で探す |
| Node.js 24 以上 | アプリを作る（ビルドする）ときだけ使う。動かすときは不要 |

Maven のインストールは不要（同梱の `mvnw` を使う）。

## 使い方

### 起動と終了

| ファイル | 内容 |
|---|---|
| `start.bat` | **普段使い**。画面を組み込んだ1つのアプリ（`app\orbit.jar`）を、ウィンドウを出さずに裏で起動し、ブラウザで http://127.0.0.1:8080/ を開く。すでに動いていればブラウザを開くだけ。初回（アプリがまだないとき）は自動でビルドする（数分） |
| `stop.bat` | 停止。`start.bat` と `start-dev.bat` のどちらで起動していても止める |
| `build.bat` | アプリを作り直す。**コードを更新したら実行する**（1分ほど）。動いていれば止めて入れ替え、起動し直す |
| `start-dev.bat` | **開発用**。画面を変更するとすぐ反映される（http://127.0.0.1:5173/ 。ウィンドウが2つ開く）。普段使いとは同時に動かせないので、切り替えるときは `stop.bat` を先に実行する |

- **ログ**：普段使いのアプリのログは `%USERPROFILE%\.mytask-manager\logs\orbit.log` に残る（起動しないときはここを見る）
- **接続できる範囲**：自分の PC からだけ（`127.0.0.1` で待ち受ける）。ログイン機能がないので、同じネットワークの他の PC には公開しない。さらに、ブラウザで開いた別のサイトから裏で操作されないよう、他サイトからの更新や、この PC 以外を指す宛先へのリクエストも拒否する（詳細は [api-design.md](docs/api-design.md) の「接続の制限」）

起動中に PC の日付が変わると、0時に繰り返しタスクが生成される。アプリを止めていた日の分は、次に起動したときに**直近の1回分だけ**生成される。

### ログイン時に自動で起動する（任意）

- **登録**：`install-autostart.bat` をダブルクリックする。スタートアップフォルダーに「Orbit」のショートカット（`start.bat --background`、最小化）が作られ、次回のサインインから自動で起動する（ブラウザは開かない）
- **解除**：`uninstall-autostart.bat` をダブルクリックする

### エリア（Project / Internal など）

タスクを「Project」「Internal」のように分けられる。サイドバー上部のタブで切り替えると、Today も含めてそのエリアだけを表示する（「すべて」なら全部を色付きバッジ付きで表示）。

- 追加したタスクは選んでいるエリアに入る。クイック追加で `@Internal` と書けば、そのエリアに入れられる（名前の先頭だけでもよい）
- 詳細パネルの「エリア」で付け替えられる。サブタスクは親と同じエリアに入る
- 繰り返しルールにもエリアを設定でき、生成されるタスクはそのエリアに入る
- エリアの追加・名前と色の変更・並べ替え・削除は設定画面で行う（10個まで）

### データの保存場所

```
%USERPROFILE%\.mytask-manager\data\mytask.mv.db
```

リポジトリの外に置いているので、`git clean` やリポジトリの作り直しでは消えない。
場所を変えたいときは、バックエンドの起動引数で `--mytask.data-dir=<フォルダー>` を指定する。

### バックアップ

**自動バックアップ**：アプリの起動時と毎日0時過ぎに1回、次のフォルダーに JSON を保存する（直近14日分を残す）。

```
%USERPROFILE%\.mytask-manager\backups\orbit-auto-YYYYMMDD.json
```

**コピー先（おすすめ）**：設定画面の「コピー先」に OneDrive などの同期フォルダーを指定すると、自動バックアップをそこにも置く（そこでも直近14日分を残す）。この PC のディスクが壊れても、バックアップが残る。コピーに失敗したときは設定画面に理由が出る。「今すぐバックアップ」で、その場で保存し直せる。

それぞれの場所と役割は、設定画面の先頭「保存場所」にまとめて出している（パスをコピーできる）。

**手動のエクスポート／インポート**は、画面左の「設定」から行う。

- **エクスポート**：`orbit-YYYYMMDD-HHmm.json` がダウンロードされる。タスク・サブタスク・繰り返しルールを ID ごと保存する。定期的に取っておくこと
- **インポート**：ファイルを選ぶと、まず中身を検証して件数を表示する。確認すると**現在のデータをすべて置き換える**。不正なファイルは理由を表示して取り込まない。自動バックアップは、設定画面の一覧の「復元」からも戻せる

> **H2 のバージョンを上げるとき**：H2 のデータファイルはメジャーバージョン間で互換性がない。`backend/pom.xml` の `h2.version` を上げる前に必ずエクスポートし、上げたあと（空の DB で起動して）インポートで戻す。

## 開発

| 用途 | コマンド | 場所 |
|---|---|---|
| 開発用にまとめて起動 | `start-dev.bat`（下の2つを別ウィンドウで起動） | ルート |
| バックエンドの起動 | `.\mvnw.cmd spring-boot:run`（ポート 8080） | `backend/` |
| バックエンドのテスト | `.\mvnw.cmd test` | `backend/` |
| フロントエンドの起動 | `npm run dev`（ポート 5173、`/api` を 8080 へ転送） | `frontend/` |
| フロントエンドのテスト | `npm test`（Vitest） | `frontend/` |
| 型チェック・ビルド | `npm run build` | `frontend/` |
| lint | `npm run lint`（oxlint） | `frontend/` |
| E2E テスト | `npm run e2e`（Playwright） | `frontend/` |

- **テスト用の DB**：バックエンドのテストはメモリ上の DB を使う（`src/test/resources/config/application.yml`）。普段使いのデータには触れない
- **E2E テストの実行環境**：バックエンド（18080）とフロントエンド（15173）を、空の一時 DB（OS の一時フォルダーの `mytask-e2e-*`）で自動起動する
  - 普段使いのアプリを起動したままでも実行できる
  - ブラウザは Windows の Edge を使うので、ダウンロードは不要
- **日時を固定したテスト**：「今日」「期限切れ」「繰り返しの生成」は `java.time.Clock` を注入しているので、テストでは日時を固定・移動して確認できる（`MutableClock`）

## 構成

```
mytask-manager/
├── start.bat / stop.bat   起動・終了（普段使い）
├── build.bat              普段使い用アプリ（app\orbit.jar）を作る
├── start-dev.bat          開発用の起動
├── install-autostart.bat / uninstall-autostart.bat   サインイン時の自動起動の登録・解除
├── app/                   build.bat が作るアプリ（Git の管理外）
├── docs/                  要件定義・設計書
├── backend/               Spring Boot 4 / Java 21 / Spring Data JPA / H2 / Flyway
│   └── src/main/java/com/masatto/mytask/
│       ├── task/          タスク（一覧の組み立て・ステータスの連動）
│       ├── rule/          繰り返しルール（発生日の計算・生成処理）
│       ├── backup/        エクスポート／インポート
│       ├── common/        共通エラー形式・ヘルスチェック
│       └── config/        Clock・スケジューラー
└── frontend/              React 19 / TypeScript / Vite / TanStack Query / React Hook Form + Zod / React Router
    ├── src/
    │   ├── api/           API の型と呼び出し
    │   ├── hooks/         データ取得・更新、未保存の変更の確認
    │   ├── components/    一覧の行・詳細パネル・ルール編集・ダイアログ
    │   ├── pages/         各画面
    │   └── lib/           日付・グループ分け・繰り返しの表示
    └── e2e/               Playwright の E2E テスト
```

## 主な設計判断

| 判断 | 理由 |
|---|---|
| 「今日」「期限切れ」の判定と並び順はサーバーで確定させる | 表示ロジックをフロントに散らさない。フロントは受け取った順に並べ、日付で見出しを付けるだけ |
| リクエストは専用の DTO で受ける（Entity を直接受けない） | クライアントが送った `id` で既存データが上書きされる穴を作らないため |
| 期限のないサブタスクは親の期限でビューを判定する | 繰り返しのひな形から作るサブタスクは期限を持たないため。そのままだと親が「期限なし」にも出てしまう |
| 繰り返しは「最後に生成した発生日」で判定する | 逃した回を大量に作らない（直近の1件だけ）／生成済みのタスクを削除しても作り直さない |
| サブタスクの入れ子は DB の複合外部キーでも禁止する | アプリのチェックをすり抜けても、データが壊れないようにするため（db-design 3.4） |
| Flyway でスキーマを管理し、Hibernate は `validate` のみ | 長く使う実データを、自動のスキーマ変更から守るため |
| インポートの検証は「実際に取り込んでからロールバック」で行う | 参照関係だけでなく DB の制約違反まで、確認ダイアログを出す前に検出できる |
| 未保存の変更は、すべての画面遷移で確認する（`useBlocker`） | パネルの切り替え・サイドバー・ブラウザの戻るのどれでも、編集内容を黙って失わないため |
